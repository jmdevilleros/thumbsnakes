# thumbsnakes

> **Experimental, educational repository.** This project exists to learn and demonstrate how to build a Flutter + Flame game with the ITSD method (spec, plan, decisions and phased implementation). It is not a finished product, it is not published on Google Play and it is not actively maintained.

Android snake game for two thumbs: two snakes, each with its own on-screen virtual joystick (Flutter + Flame, ITSD).
